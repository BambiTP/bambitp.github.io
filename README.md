# bambitp.github.io

Landing page for my TagPro projects: clones, bots, userscripts, map tools, stats and spreadsheets.

**https://bambitp.github.io/**

`index.html` is the whole site, plain HTML, CSS and a little JavaScript with no build step. The project list is
the `P` array near the top of the script: add one line to add a project. Screenshots live in `img/`.
`.nojekyll` keeps GitHub Pages from running it through Jekyll.
